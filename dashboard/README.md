# 📊 Sales Performance Dashboard 

This folder contains the primary dashboard visuals for the **Sales Performance & Forecasting Analysis** project.

## Dashboard Overview

The Excel dashboard provides an interactive view of business performance from **2019–2022**, allowing users to analyze results across customers, products, regions, and time periods.

### Key KPIs
- Total Revenue: **$2.30M**
- Total Profit: **$286K**
- Profit Margin: **12.47%**
- Total Orders: **5,009**
- Average Order Value: **$459**

### Dashboard Analysis
- Monthly and quarterly revenue trends
- Revenue and profit by region
- Revenue and profit by product category
- Revenue and profit by customer segment
- Top 10 strategic accounts
- Average shipping days by region

### Interactive Features
- Year, Region, Segment, and Category slicers
- Year, Quarter, Month, and Day timelines
- Dynamic PivotTables and PivotCharts
