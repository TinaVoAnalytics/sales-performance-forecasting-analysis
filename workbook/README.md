# 📗 Excel Analysis Workbook 

This folder contains the complete interactive Excel workbook for the **Sales Performance & Forecasting Analysis** project.

## Workbook Features

- Power Query data preparation
- KPI calculations
- PivotTables and PivotCharts
- Interactive slicers and timelines
- Sales and profitability analysis
- Customer, product, and regional analysis
- Shipping performance analysis
- 2023 revenue forecasting using FORECAST.ETS
- Forecast backtesting and MAPE validation

## Key Outputs

- Total Revenue: **$2.30M**
- Total Profit: **$286K**
- Profit Margin: **12.47%**
- Total Orders: **5,009**
- Average Order Value: **$459**
- 2023 Forecast Revenue: **$860K**
- Backtest MAPE: **47.99%**

> Open the `.xlsx` file in Microsoft Excel for the complete interactive experience.
